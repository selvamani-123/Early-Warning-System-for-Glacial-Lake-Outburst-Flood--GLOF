  Anti-leakage measures implemented:

  [1] SPLIT BEFORE AUGMENTATION
      train_test_split() was called FIRST on the raw (unaugmented) dataset.
      Augmentation was only applied to X_train AFTER the test set was frozen.

  [2] AUGMENTATION ON TRAIN ONLY
      CRITICAL and HIGH oversampling + noise injection was applied
      exclusively to the training partition. X_test and y_test were
      never touched after the initial split.

  [3] LABEL GENERATION ISOLATION
      generate_risk_labels() was applied to raw data before the split,
      then only to augmented training rows. Test labels came from
      the pre-split labeling pass.

  [4] CV SCOPE LIMITED TO TRAINING DATA
      cross_val_score() was run on (X_train_aug, y_train_aug) only.
      Test data was completely excluded from cross-validation.

  [5] NO FEATURE SCALER LEAKAGE
      Random Forest does not require scaling. No StandardScaler or
      MinMaxScaler was fitted on combined train+test data.

  [6] STRATIFIED SPLIT
      stratify=y parameter ensures proportional class representation
      in both train and test, preventing leakage through class imbalance.

================================================================================
  SECTION 10 -- DATA PROVENANCE REPORT (Per Feature)
================================================================================

  ---- Feature: rainfall ----
  Source          : Open-Meteo Historical Archive REST API
  Dataset name    : ERA5-Land Reanalysis (ECMWF)
  Collection      : Daily rain_sum (mm) queried per glacier lat/lon.
                    Date range: 3 years back from current date.
                    API endpoint: archive-api.open-meteo.com/v1/archive
  Type            : REAL-WORLD
  Notes           : ERA5-Land is a widely-used global reanalysis dataset
                    produced by the European Centre for Medium-Range
                    Weather Forecasts (ECMWF). Spatial resolution ~9km.

  ---- Feature: temperature ----
  Source          : Open-Meteo Historical Archive REST API
  Dataset name    : ERA5-Land Reanalysis (ECMWF)
  Collection      : (temperature_2m_max + temperature_2m_min) / 2.0
                    Daily mean temperature in degrees Celsius.
  Type            : REAL-WORLD
  Notes           : Temperature is a real measured/reanalysis quantity.
                    No synthetic component.

  ---- Feature: humidity ----
  Source          : Open-Meteo (partial) + Statistical Heuristic
  Dataset name    : ERA5-Land + Rule-Based Approximation
  Collection      : If rainfall > 0 mm: sampled from Uniform(75%, 95%)
                    Else              : sampled from Uniform(40%, 70%)
                    This approximation reflects the well-known strong
                    correlation between precipitation and relative humidity
                    in mountainous terrain.
  Type            : SEMI-SYNTHETIC
  Notes           : True relative humidity at high-altitude glacier sites
                    was not directly available from the free Open-Meteo API
                    tier. A scientifically-motivated heuristic was used.
                    This feature has the LOWEST importance (0.41%) in the
                    model, minimising the impact of this approximation.

  ---- Feature: lake_area ----
  Source          : GLIMS Glacier Database / Published Literature
  Dataset name    : GLIMS (Global Land Ice Measurements from Space) +
                    Randolph Glacier Inventory (RGI v7)
  Collection      : Static curated metadata for 8 high-risk glacial lake
                    sites. Surface area in km2 from published GLOF studies.
  Type            : REAL-WORLD
  Notes           : Values match peer-reviewed literature (Emmer 2017,
                    ICIMOD GLOF Risk Assessments). Updated periodically
                    as lakes grow due to climate change.

  ---- Feature: glacier_area ----
  Source          : GLIMS / NASA NSIDC / RGI v7
  Dataset name    : Randolph Glacier Inventory version 7
  Collection      : Catchment glacier surface area (km2) per lake site.
                    Derived from satellite remote sensing (Landsat/Sentinel).
  Type            : REAL-WORLD
  Notes           : Glacier area is a static snapshot. In production,
                    this should be updated via annual satellite retrieval
                    as glaciers retreat.

  ---- Feature: estimated_melt_rate (melt_rate_index) ----
  Source          : Computed internally from temperature + elevation
  Dataset name    : DERIVED FEATURE
  Collection      : Formula: max(0, temperature) x (elevation / 5000.0) x 0.1
                    Physics-informed heuristic estimating daily melt intensity.
                    Positive temperature at high elevation implies greater
                    ice-melt contribution to lake inflow.
  Type            : DERIVED (not a direct sensor measurement)
  Notes           : In a production system, this should be replaced with
                    actual melt rate data from mass-balance models
                    (e.g., GloGEM, PyGEM) or in-situ sensors.

  ---- Feature: risk_labels (LOW / MODERATE / HIGH / CRITICAL) ----
  Source          : Programmatic deterministic rule engine
  Dataset name    : label_generation.py (GLOF domain expert rules)
  Collection      : Rules applied to 3 derived features post-engineering.
                    No manual labeling, no crowd-sourcing, no LLM.
                    See Section 12 for full rule definitions.
  Type            : DERIVED / RULE-BASED
  Notes           : Rules are grounded in ICIMOD GLOF risk frameworks
                    and peer-reviewed GLOF literature. Thresholds were
                    calibrated against known historical GLOF events.

  ---- Feature: elevation ----
  Source          : GLIMS / NASA SRTM Digital Elevation Model
  Dataset name    : SRTM DEM + GLIMS Glacier Database
  Collection      : Static field from curated glacier metadata.
                    Elevation of the glacial lake in meters above sea level.
  Type            : REAL-WORLD

  ---- Feature: rainfall_intensity (derived) ----
  Source          : Computed from rainfall + historical baseline
  Dataset name    : DERIVED FEATURE
  Collection      : Formula: rainfall / historical_avg_rainfall (5.0 mm)
                    Captures anomalous precipitation relative to baseline.
                    Ratio > 5.0 means rainfall is 5x the historical average.
  Type            : DERIVED

  ---- Feature: water_accumulation_score (derived) ----
  Source          : Computed from rainfall, lake_area, melt_rate_index
  Dataset name    : DERIVED FEATURE
  Collection      : Formula: (rainfall + melt_rate_index * 50) / lake_area
                    Proxy for inflow rate per unit of lake capacity.
                    Smaller lakes with high inflow fill faster = higher risk.
  Type            : DERIVED

  ---- Feature: seasonal_index (derived) ----
  Source          : Computed from month + temperature
  Dataset name    : DERIVED FEATURE
  Collection      : June-Sept (melt season): multiplier = 1.5
                    May, October:            multiplier = 1.2
                    All other months:        multiplier = 1.0
                    Then multiplied by: 1.0 + max(0, temp) / 20.0
  Type            : DERIVED

================================================================================
  SECTION 12 -- LABEL GENERATION METHODOLOGY
================================================================================

  File: label_generation.py
  Method: Deterministic rule-based classification (no ML, no manual labeling)
  Input features used: rainfall_intensity, water_accumulation_score,
                       melt_rate_index

  Rules (evaluated in priority order, highest first):

  ---- CRITICAL RISK ----
  Condition A: rainfall_intensity > 5.0  AND  water_accumulation_score > 50
  Condition B: melt_rate_index > 2.0     AND  water_accumulation_score > 60
  Trigger    : Condition A OR Condition B
  Meaning    : Catastrophic scenario. Rainfall 5x above average with
               extreme lake inflow rate, OR intense glacier melt (anomalously
               warm) driving rapid lake level rise. Moraine breach imminent.
  Count      : 3 natural cases (0.04% of full dataset)

  ---- HIGH RISK ----
  Condition A: rainfall_intensity > 3.0  AND  water_accumulation_score > 30
  Condition B: melt_rate_index > 1.5     AND  water_accumulation_score > 40
  Trigger    : Condition A OR Condition B (if not already CRITICAL)
  Meaning    : Significant GLOF risk. Heavy rainfall or accelerated melt
               causing notable lake level rise. Emergency preparedness
               required.
  Count      : 32 natural cases (0.42% of full dataset)

  ---- MODERATE RISK ----
  Condition A: rainfall_intensity > 1.5
  Condition B: water_accumulation_score > 15
  Condition C: melt_rate_index > 1.0
  Trigger    : Condition A OR B OR C (if not already HIGH or CRITICAL)
  Meaning    : Elevated but manageable conditions. Above-average rainfall
               or melt with lake levels rising. Heightened monitoring needed.
  Count      : 1,672 natural cases (21.79% of full dataset)

  ---- LOW RISK ----
  Trigger    : Default (none of the above conditions met)
  Meaning    : Normal glacier lake conditions. All parameters within
               safe operating thresholds. Standard monitoring applies.
  Count      : 5,965 natural cases (77.76% of full dataset)

  Scientific basis for thresholds:
  - Rainfall intensity of 5.0x corresponds to extreme precipitation (>3 sigma
    above historical mean), consistent with ICIMOD extreme event definitions.
  - Water accumulation score thresholds derived from simplified hydraulic
    pressure models used in GLOF risk assessments (Carrivick & Tweed 2016).
  - Melt rate thresholds calibrated against known warm-spell GLOF events
    in Bhutan (Lugge Tsho 1994) and Nepal (Dig Tsho 1985).
  - Reference: Emmer A. (2017). Geomorphologically effective floods from
    moraine-dammed lakes in the Cordillera Blanca, Peru. Quaternary Science.
